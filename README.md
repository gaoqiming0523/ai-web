# AI 能源管理助手

一个基于 AI 的智能能源管理助手，支持语音交互和文本对话，帮助用户优化能源使用和管理。

## ✨ 主要功能

- 🎤 语音交互：支持实时语音识别和对话
- 🤖 多模型支持：集成 OpenAI GPT-4.1 和 Google Gemini
- 💡 智能分析：提供专业的能源管理建议
- 📊 数据可视化：直观展示能源使用情况
- 🔄 实时响应：快速处理用户查询

## 🚀 快速开始

### 环境要求

- Node.js 22 或更高版本
- npm 或 yarn 包管理器
- 现代浏览器（Chrome、Edge、Safari 等）

### 安装步骤

1. 克隆项目
```bash
git clone [项目地址]
cd ai-web
```

2. 安装依赖
```bash
npm install
# 或
yarn install
```

3. 配置环境变量
```bash
# 在项目根目录创建 .env 文件
OPENAI_API_KEY=你的OpenAI API密钥
GEMINI_API_KEY=你的Gemini API密钥
```

4. 启动开发服务器
```bash
npm run dev
# 或
yarn dev
```

5. 访问应用
打开浏览器访问 `http://localhost:8080`

## 🛠️ 技术栈

- React 18
- Vite
- TailwindCSS
- OpenAI API
- Google Gemini API
- React Speech Recognition

## 📝 使用说明

1. 点击【免费试用】进入语音交互页面
2. 选择 AI 模型（GPT-4.1 Mini 或 Gemini Pro）
3. 使用语音或文本输入您的问题
4. 获取 AI 助手的专业建议
